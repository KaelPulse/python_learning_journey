# Day 1 Notes

First day of learning Python. Kept it pretty basic - just getting used 
to how the syntax works and how a script actually runs.

## What I learned
- print() - obviously, but also that you can concatenate strings inside 
  it using +
- input() - takes whatever the user types and returns it as a string
- Storing input in a variable so you can use it more than once
- Variables can be reassigned at any point, they're not locked in
- len() - counts characters in a string, works on variables or directly 
  on input()

## Scripts I wrote
- **Order Ticket Practice.py** - takes an order and a name, prints a 
  little order summary, shows the length of the item name
- **Two Truths and a Variable.py** - takes two facts as input, prints 
  them, then reassigns one variable in code to show how that changes 
  the output
- **ID Card Generator.py** - takes name, city, and favourite number, 
  prints it formatted like an ID card with labels
