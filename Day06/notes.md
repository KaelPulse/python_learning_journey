## What I learned
- Functions are defined with def, and can take parameters - values 
  passed in when you call the function, letting the same function 
  logic run differently depending on what's passed in
- Mixed up asking for input inside a function vs passing a value in as 
  a parameter - the point of a parameter is that the function doesn't 
  need to ask for its own input, the caller provides it
- while loops keep repeating as long as a condition stays True - 
  unlike a for loop with range(), you control when it stops yourself, 
  usually by changing a variable inside the loop. Forgetting to change 
  that variable would cause an infinite loop
