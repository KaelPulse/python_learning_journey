# Python Learning Journey

Just documenting my Python progress as I learn it, day by day. 
No big projects yet, just small scripts and notes on what I picked up.

## Log

**Day 1** - print(), input(), string concatenation, variables, len()
Built a few small scripts: an order ticket generator, a "two truths" 
variable demo, and a digital ID card generator.

**Day 2** - float()/int() casting, round(), f-strings, order of operations
Built an age calculator, a restaurant bill splitter with service charge, 
and a grocery receipt generator with a discount calculation.

**Day 3** - comparisons, modulo, nested if statements, if/elif/else, 
logical operators (and/or/not)
Built a rollercoaster pricing script, a number sorter that handles ties, 
a leap year checker, movie ticket pricing, a BMI calculator with 
age-tailored advice, a gym membership cost calculator with stacking 
discounts, and a League of Legends-themed spin on the Treasure Island 
project.

## Why this repo exists
Mostly for myself, to keep track of progress and look back on later. 
Also figured it's worth having something on GitHub while I learn instead 
of waiting until I have a "real" project.

## Structure
Each day gets its own folder with the scripts I wrote and a short 
notes.md on what I learned.
